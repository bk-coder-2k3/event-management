# VizhaSpace Luxury UI/UX Design System

## Brand identity

VizhaSpace is a premium event and wedding marketplace.

The experience must communicate:
- Luxury
- Trust
- Elegance
- Simplicity
- Professionalism
- Premium hospitality

Design inspiration: luxury hospitality, editorial wedding magazines,
premium travel platforms and modern SaaS products.

## Visual language

### Colors
- Background: #FAF8F4
- Surface: #FFFFFF
- Primary text: #24211F
- Secondary text: #77716B
- Champagne gold: #B99A62
- Dark background: #211D1A
- Border: #EAE5DC
- Success: #55745B
- Error: #B94A48

Use gold sparingly for highlights and important actions.

### Typography
- Headings: Playfair Display
- Body: Inter
- Use strong typographic hierarchy.
- Maintain excellent readability.
- Avoid excessive font weights.

### Layout
- Spacious layouts.
- Consistent spacing system.
- Clean grid structures.
- Elegant navigation.
- Large, high-quality event photography.
- Rounded corners used consistently.
- Subtle borders and soft shadows.

## Customer experience

Design premium interfaces for:
- Homepage
- Event category discovery
- Wedding venues
- Vendor discovery
- Vendor profile pages
- Venue detail pages
- Search and filtering
- Event enquiries
- Booking requests
- Customer dashboard
- Saved vendors and venues

Prioritize visual photography, transparent pricing,
trust indicators and simple enquiry flows.

## Vendor experience

Design professional interfaces for:
- Vendor registration
- Vendor onboarding
- Business profile management
- Portfolio and gallery management
- Services and pricing
- Enquiry management
- Booking management
- Availability calendar
- Performance dashboard

Vendor dashboards must prioritize functionality
without losing the VizhaSpace visual identity.

## Management experience

Design clean administrative interfaces for:
- Vendor verification
- Customer management
- Vendor management
- Booking oversight
- Category management
- Platform analytics

## Interaction and usability

- Responsive on mobile, tablet and desktop.
- Smooth and subtle animations.
- Accessible contrast and keyboard navigation.
- Clear loading, empty, error and success states.
- Consistent buttons, inputs, dialogs and tables.
- Clear form validation.
- Meaningful feedback for every important action.

## Technical rules

- Preserve existing application architecture.
- Reuse existing components.
- Prefer reusable design tokens.
- Use Tailwind CSS where available.
- Use shadcn/ui where appropriate.
- Use Lucide icons.
- Use Motion only when animations add value.
- Avoid unnecessary dependencies.
- Never break existing APIs or business logic.
- Maintain performance and accessibility.

## Design restrictions

Never produce:
- Generic AI-generated dashboard layouts.
- Excessive gradient backgrounds.
- Overused glassmorphism.
- Excessive gold-colored surfaces.
- Random icon combinations.
- Unnecessary decorative elements.
- Inconsistent spacing and typography.
- Unresponsive layouts.

## Quality assurance

Before completing any UI task:

1. Inspect the existing project.
2. Understand the current components and architecture.
3. Apply the VizhaSpace design system.
4. Implement the requested functionality.
5. Test mobile and desktop layouts.
6. Check accessibility and visual consistency.
7. Fix browser console errors.
8. Verify existing functionality remains intact.
